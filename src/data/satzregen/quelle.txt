# Regis Satzregen – die Sätze, von Hand in Satzglieder (Chunks) geteilt.
# scripts/build-satzregen.mjs macht daraus src/data/satzregen/saetze.json.
#
# Eine Zeile = ein Satz:   chunk / chunk / chunk .  = English gloss  {flags}
#   Chunks so geschrieben, wie sie mitten im Satz stehen („ich“, „am Montag“, „Pizza“).
#   Der erste Buchstabe von Platz 1 wird nur in der Anzeige großgeschrieben.
#   *  konjugiertes Verb          ^  Subjekt
#   ~  anderer Verbteil (Infinitiv, Partizip, Präfix) – nie auf Platz 1
#   !  darf nicht auf Platz 1, obwohl die Vorfeld-Regel es erlauben würde
#   Ende: „ .“ oder „ ?“ nach dem letzten Chunk.
#   {nv}            keine Vorfeld-Varianten (nur Grundform + alt)
#   {alt 0 1 3 2}   weitere richtige Reihenfolge, als Indizes der Chunks (mehrere möglich)
#   {rule …}        eigene Regelzeile für „Diese Sätze waren knifflig“
# Quelle: Sätze aus dem Wortschatz (Beispielsätze, vertont), aus den Grammatik-Übungen und
# aus Lindenau stehen hier wortgleich; der Builder findet ihre Herkunft und das Audio selbst.
# Alle anderen sind für das Spiel geschrieben (2026-10-28).
