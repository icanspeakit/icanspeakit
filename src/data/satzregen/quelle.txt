# Regi's Sentence Rain – the sentences, split into chunks by hand.
# scripts/build-satzregen.mjs turns this into src/data/satzregen/saetze.json.
#
# One line = one sentence:   chunk / chunk / chunk .  = note shown under the solved line  {flags}
#   Chunks are written as they stand inside the sentence ("yo", "los sábados", "en un bar").
#   The first letter of slot 1 is capitalised in the display only, and a question gets its ¿ there.
#   *  finite verb (or auxiliary)      ^  subject
#   ~  other verb part (participle or infinitive after the auxiliary)
#   End: " ." or " ?" after the last chunk.
#   {alt 3 0 1 2}   another correct order, as chunk indices (several allowed)
#   {free 1<2 3-4}  every order of the chunks with these conditions, built into alts:
#                   1<2 = chunk 1 somewhere before chunk 2; 3-4 = chunk 3 right before chunk 4
#   {rule …}        own rule line for "These sentences were tricky"
#   {es419 …}       note for a future Latin American mode (content-plan §1.5)
#
# Spanish word order is freer than English, and the game must never reject a good sentence. What
# counts as correct:
#   statements  the neutral order and what speakers really say: time or place at the front, the
#               subject after the verb. A verb at the very end ("Yo café tomo") is not accepted,
#               and neither is an object before its verb. Those can be heard for emphasis, but
#               they are not what a learner should build.
#   questions   the question word stays right before the verb; everything else may move
#               (¿Dónde vives tú?, ¿Tú dónde vives?).
#   pronouns    me, te, lo, la, le, nos, os, se stay right before the verb, as do no and haber.
# Modes keep their German ids: v2 = statements and wh-questions (A1), janein = yes/no questions
# (A1), klammer = object pronouns before the verb (A2), nebensatz = indirect questions (B1).
# Source: all sentences written for the game by the games run (2026-11-06), Castilian Spanish.
