# icanspeak English: suggestions to curated material lists, drafts v1 (2026-11-15)

Lane `outreach` of the traction batch (`prompts/traction/outreach.md`). Claude researched the lists and wrote
the drafts. **Edgar sends.** When one has gone out, put the date in the tracking table, and later the answer.

Why: on deutschacademy, one email to the Deutscher Bildungsserver (2026-10-04) got `/wissen` listed. The
listing still brings ~40 sessions a month, and search engines and ChatGPT both see the link
(`deutschacademy/docs/seo-outreach-v1.md`). This file applies the same idea to
https://icanspeak.it/english/.

Rules for every draft (same as deutschacademy's):
- Each mail goes out on its own, to the person named on the page if there is one. No mail merge, no BCC.
- Each one says openly that it comes from the person who made the site, and proposes exactly one page.
- No paid listings, no link swaps, no "write for us" blogs, no Reddit/forum posts.
- No numbers in the drafts on purpose. The `downloads` and `worksheets` lanes are still building the pages,
  and counts change. If you want a count (e.g. "worksheets for N grammar topics"), read it off the live page
  on the day you send.
- Before each mail, open the list page once. Check it is still maintained and that the contact is still the
  one in the table.
