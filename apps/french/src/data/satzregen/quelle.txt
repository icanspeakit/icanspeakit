# Regi's Sentence Rain – the sentences, split into chunks by hand.
# scripts/build-satzregen.mjs turns this into src/data/satzregen/saetze.json.
# Variety: standard French of France (fr-FR). Québec differences only as {frCA …}.
#
# One line = one sentence:   chunk / chunk / chunk .  = English translation shown under the solved line  {flags}
#   Chunks are written as they stand inside the sentence ("je", "à Lyon", "n'ai").
#   Elided forms are never split at the apostrophe: j'ai, l'a, n'ai, s'il, qu'est-ce que, d'ici.
#   Straight apostrophe ' in the data. Punctuation sits on the last tile (", s'il vous plaît").
#   No non-breaking spaces here: the game adds one before "?" when it shows the sentence.
#   The first letter of slot 1 is capitalised in the display only. Questions have no ¿.
#   *  finite verb (or auxiliary; an elided tile like j'ai or l'a counts as the verb)
#   ^  subject
#   ~  other verb part (participle or infinitive after the auxiliary)
#   End: " ." or " ?" after the last chunk.
#   {alt 3 0 1 2}   another correct order, as chunk indices (several allowed)
#   {free 1<2 3-4}  every order of the chunks with these conditions, built into alts:
#                   1<2 = chunk 1 somewhere before chunk 2; 3-4 = chunk 3 right before chunk 4
#                   Only where the order is truly free (it almost never is in French).
#   {rule …}        own rule line for "These sentences were tricky"
#   {frCA …}        note for a future Canada (Québec) mode (content-plan §1.5)
#
# French word order is much less free than Spanish. What counts as correct:
#   statements  subject – verb – object – place/time. Fronted adverbials need a comma ("Demain, je
#               pars"), which cannot sit on a movable tile, so they are not offered. Two adverbials
#               at the end may swap when both orders are natural ({alt}).
#   adjectives  BAGS adjectives (beau, bon, grand, petit, joli, vieux, gros …) before the noun, colours
#               and nationalities after it. Each is its own tile, so the player must place it.
#   adverbs     short adverbs (bien, déjà, beaucoup, vraiment) between avoir/être and the participle.
#   questions   one tile set = one form. Inversion with a subject noun ("Où habitent tes parents ?"),
#               est-ce que + statement order, or intonation ("Tes parents habitent où ?"). Where the
#               tiles allow several natural orders, all are listed as {alt}.
#   pronouns    me, te, le, la, les, lui, leur, nous, vous, y, en stand right before the verb (before
#               avoir/être in the perfect); ne … pas wraps the conjugated verb (je ne travaille pas,
#               je n'ai pas mangé).
# Modes keep their ids: v2 = statements and wh-questions, adjectives, adverbs (A1), janein = yes/no
# questions (A1), klammer = pronouns before the verb and ne … pas (A2), nebensatz = indirect questions (B1).
# Source: all sentences written for the game by the games run (2026-11-12), French of France.
