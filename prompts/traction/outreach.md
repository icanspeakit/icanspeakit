# Lane: outreach (step 1)

You write, you don't send. Every email or form submission is Edgar's to send. You own
`docs/marketing/**` in this repo (create it if missing, with a `README.md` index table:
file, purpose, date, like `deutschacademy/docs/marketing/README.md`).

On deutschacademy one email to the Deutscher Bildungsserver (a curated DaF/DaZ material list) still
brings ~40 sessions a month, and the listing is a trusted backlink that search and ChatGPT both see.
Read `deutschacademy/docs/seo-outreach-v1.md` first: its structure, tone, the tracking table.

## Tier 1: targets (research, write down)
- 20–30 curated, still-maintained lists of free English-learning / ESL / EFL teaching material where
  a free, no-account site can be suggested: national education servers and teacher portals
  (Spanish, Portuguese/Brazilian, Italian, German, French ones for English teachers), university
  ESL resource pages, library guides, teacher associations, well-kept "free ESL resources" pages.
- For each: name, URL of the list page, who maintains it, how to suggest (email, form), last
  update you can see, why it fits, which icanspeak page to propose (`/english/knowledge`,
  `/english/teachers/worksheets/`, an exam page). Verify every URL loads. No paid listings, no link
  farms, no "write for us" SEO blogs, no Reddit/forum spam.
- Also the Spanish and French courses: 5–10 targets each for teachers of Spanish/French, same
  columns, marked "later" (those courses get their downloads in a later batch).

## Tier 2: the drafts
- `docs/marketing/outreach-english-v1.md`: tracking table (target, contact, status, date sent,
  answer) plus one short email per target in the language of the target (German to a German server,
  Spanish to a Spanish one …). Under 120 words each, personal, says what the page offers in one
  line, no superlatives, no invented numbers, signed by Edgar. Subject lines that a busy editor opens.
- Follow-up template after 14 days.
- Note which pages must exist before sending (the `downloads` and `worksheets` lanes build them;
  read their lane files) so Edgar sends only after the release.

## Tier 3: ChatGPT/Bing visibility check (no browser login needed)
- Write `docs/marketing/ai-visibility-english-v1.md`: 15 questions learners and teachers actually ask
  (in English, Spanish, Portuguese, Hindi, Vietnamese, Indonesian), e.g. "free English grammar
  worksheets B1 pdf". For each: what deutschacademy's German equivalent is, which icanspeak page
  should answer it, and a monthly check Edgar can run by hand (ask ChatGPT with search, note
  whether icanspeak is cited). Baseline column left empty for Edgar.
- Add both files to `docs/marketing/README.md`, commit (`docs: …`).
